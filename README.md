# Stream Player IPTV para Android

Canal público de descarga y actualizaciones. No incluye fuentes, canales ni suscripciones.

[Descargar Android 0.1.15](https://github.com/faqunditto-byte/stream-player-iptv-updates/releases/download/android-v0.1.15/Stream-Player-IPTV-Android-0.1.15-Prueba.apk)

Instalá sobre la versión anterior sin desinstalar para conservar tus cuentas. Versión de prueba con nuevo diseño azul y anuncios de prueba.

El archivo updates.json conserva la dirección que consultan las versiones antiguas de Android. Desde 0.1.14 también se usa el catálogo android-updates.json del repositorio público stream-player-comunidad. Ambos apuntan al mismo APK y se mantendrán coordinados.

Este repositorio contiene documentación y metadatos de descarga, no el código fuente, claves privadas ni cuentas IPTV.

Windows para Microsoft Store está en un repositorio privado separado. Windows Comunidad conserva su canal público independiente.
